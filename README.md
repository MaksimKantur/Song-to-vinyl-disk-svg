# Song → SVG

Превращает аудио в векторный круговой рисунок для переноса на печатную форму
(лазер, фотополимер, плоттер, трафарет).

## Запуск

Нужны `ffmpeg`/`ffprobe` в PATH.

```sh
.venv/bin/pip install -r backend/requirements.txt
cd frontend && npm install && npm run build && cd ..
.venv/bin/python main.py          # → http://127.0.0.1:8000
```

Разработка фронтенда с hot reload: `python main.py` + `cd frontend && npm run dev`
(→ http://localhost:5173, `/api` проксируется на :8000).

## Как устроено

- `backend/audio.py` — декодирование через ffmpeg (моно, 32 кГц), STFT один раз на трек,
  сведение в сетку «время × лог-частотные полосы», перевод в 0..1 (дБ, диапазон, гамма, подъём верхов).
- `backend/render.py` — геометрия и кодировки. Всё строится из «дорожек»: в полярном режиме
  одно кольцо на частотную полосу, в спирали — одна дорожка от края к центру с равной длиной ячеек.
- `frontend/` — Vite + React + TS: параметры, превью (рендер на бэке с дебаунсом), скачивание.

SVG в миллиметрах (`width="420mm"` и т.п.), слои `art` / `outline` / `title` (Inkscape-слои).

## Какую кодировку выбрать

| Кодировка | Что в SVG | Под что |
|---|---|---|
| Порог | чёрные дуги-штрихи | лазер, фотополимер, трафарет — ближе всего к классическому виду |
| Толщина дорожки | чёрные полосы переменной ширины | лазерная гравировка заливкой, фотополимер |
| Серая заливка | N оттенков серого | плёнка для фотополимера/офорта; в LightBurn каждый цвет — свой слой со своей мощностью |
| Полутоновые точки | кружки | фотополимер, шелкография |
| Штриховка | только линии, без заливок | пен-плоттер, лазер в режиме Line |
| Зигзаг | одна линия на дорожку | пен-плоттер (особенно спираль) |

Подпись — это `<text>`; для лазера/плоттера переведи её в кривые (Inkscape: Path → Object to Path).
